# Moreau

## Питч

Moreau - AI-ассистент юриста, который работает, не спит, собирает анамнез, делает сводки, не даёт ничего не забыть и помогает не утонуть в рутинных вещах, выступает секретарём и личным помощником. Telegram-бот ведёт неформальный приём клиентов, собирает суть дела и передаёт юристу для дальнейшего ознакомления в удобный момент и позволяет сэкономить время на наверстывание информации/сбор анамнеза за тот период, когда юрист был занят. Веб-приложение помогает вести дела, документы и сроки, помнит особенности каждого дела и привычки клиента. Изменения в делах происходят только с одобрения юриста - ИИ ничего не решает втихую. Это рабочий продукт с реальными пользователями, спроектированный с учётом требований 152-ФЗ так, чтобы персональные данные клиентов физически не покидали Россию. Существенная часть уже сделана, это MVP, который сейчас тестируется, для полного функционала разработка продолжается. В продукте ~43 000 строк кода и ~933 теста.
